# 🗓️ Semana 1 — Fundamentos + Blazor

**Curso 1 — ~28h**

### Segunda — Ambiente e arquitetura

**3h**

- Introdução ao .NET
- SDK / runtime
- Estrutura de um projeto ASP.NET Core
- `Program.cs`
- `appsettings.json`
- Dependency Injection
- Pipeline da aplicação

**Prática:**

- Criar um projeto ASP.NET Core do zero.
- Executar.
- Identificar onde cada configuração acontece.

🎯 **Objetivo:** conseguir olhar para um projeto ASP.NET Core e entender a estrutura básica.

---

### Terça — HTTP + Routing + Middleware

**Conteúdo**

- HTTP
- Request/Response
- Routing
- Middleware
- Pipeline
- Endpoints

**Prática:**  
Criar:

```
GET /hello
GET /hello/{name}
```

Depois criar um middleware simples para logar:

```
Request: GET /hello
Response: 200
```

🎯 **Objetivo:** entender o caminho:

```
Request
   ↓
Middleware
   ↓
Routing
   ↓
Endpoint
   ↓
Response
```

---

# 🗓️ Semana 2 — Entity Framework Core

**Curso 2 — ~26h**

Essa semana eu daria **bastante atenção**, principalmente se seu objetivo é backend.

---

### Segunda — Banco + EF Core

Aprender:

- ORM
- Entity
- `DbContext`
- `DbSet`
- Connection String
- Configuração do EF

Prática:

```
public class Task
{
    public int Id { get; set; }
    public string Title { get; set; }
}
```

Criar:

```
Task
   ↓
DbContext
   ↓
SQL Database
```

---

### Terça — Migrations

Aprender:

- Migration
- `Add-Migration`
- `Update-Database`
- Schema
- Seed

Prática:

```
Task
User
Category
```

Criar relacionamento entre elas.

---

### Quarta — CRUD

Implementar:

```
POST   /tasks
GET    /tasks
GET    /tasks/{id}
PUT    /tasks/{id}
DELETE /tasks/{id}
```

Aprender:

- LINQ
- `Where`
- `Select`
- `Include`
- `FirstOrDefault`
- `ToListAsync`

---

### Quinta — Relationships + consultas

Estudar:

```
1:N
N:N
```

Exemplo:

```
User
 │
 └── Tasks
       │
       └── Category
```

Praticar consultas reais.

Por exemplo:

> Buscar todas as tarefas pendentes do usuário X, ordenadas pela prioridade.

---

### Sexta — Performance + revisão

Entender:

- `IQueryable`
- `IEnumerable`
- Async
- Tracking
- `AsNoTracking`
- N+1 queries

Esse ponto é importante.

Tente entender **o SQL que o EF Core está gerando**, não apenas decorar os métodos.

---

### 🏠 Fim de semana — 6h

# 🗓️ Semana 3 — APIs + Segurança

**Curso 3 — primeira metade**

Agora começa a parte que eu considero especialmente importante para backend.

### Segunda — REST API

Aprender:

```
Controller
Action
Route
DTO

```

Criar:

```
GET /api/tasks
POST /api/tasks
GET /api/tasks/{id}
PUT /api/tasks/{id}
DELETE /api/tasks/{id}
```

---

### Terça — DTOs + Services

Entender a separação:

```
Controller
    ↓
Service
    ↓
Repository/EF
    ↓
Database
```

Criar:

```
TaskController
TaskService
TaskRepository
TaskDto
CreateTaskDto
UpdateTaskDto
```

Não precisa necessariamente copiar essa arquitetura para todos os projetos reais; o objetivo é entender **por que cada camada existe**.

---

### Quarta — Authentication

Estudar:

- Authentication
- Authorization
- JWT
- Claims
- Roles
- `[Authorize]`

Fluxo:

```
POST /login
     ↓
JWT
     ↓
Authorization: Bearer ...
     ↓
Protected Endpoint
```

---

### Quinta — Security

Estudar:

- Password hashing
- JWT
- CORS
- CSRF
- HTTPS
- Secrets
- Configuration

Aqui vale muito a pena entender **o problema que cada mecanismo resolve**, em vez de simplesmente decorar configuração.

# ⏱️ Sua semana ideal

Como você está fazendo **3h por dia na empresa**, eu seguiria esta rotina:

```
SEGUNDA
1h15 Curso
1h15 Código
0h30 Revisão

TERÇA
1h15 Curso
1h15 Código
0h30 Revisão

QUARTA
1h15 Curso
1h15 Código
0h30 Revisão

QUINTA
1h15 Curso
1h15 Código
0h30 Revisão

SEXTA
1h00 Curso
1h30 Projeto
0h30 Revisão

SÁBADO
3h Projeto

DOMINGO
3h Projeto/Revisão
```

**Total: 21h**

E tem uma mudança importante em relação ao plano que você trouxe: **eu não deixaria os 6h do fim de semana exclusivamente para laboratórios**. Durante a semana você já deve colocar a mão no código. O fim de semana serve principalmente para **integrar tudo e construir algo sem seguir passo a passo do curso**.

### 🎯 O objetivo das 4 semanas

Não deveria ser:

> "Terminei 84 horas de curso."

Mas sim:

> **"Consigo abrir um projeto ASP.NET Core, entender sua arquitetura, criar uma API, persistir dados com EF Core, proteger endpoints, escrever testes e fazer deploy."**

Isso te dá uma linha de estudo bem mais próxima do que você vai encontrar trabalhando como desenvolvedor .NET.
