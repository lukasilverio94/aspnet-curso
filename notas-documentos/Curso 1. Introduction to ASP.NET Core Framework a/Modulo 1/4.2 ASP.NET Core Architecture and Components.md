Estrutura do Projeto ASP.NET Core

- O projeto é organizado em pastas principais: Controllers (controladores que lidam com requisições HTTP), Models (modelos de dados e lógica de negócio), Views (visões Razor para gerar respostas HTML) e wwwroot (arquivos estáticos como CSS, JavaScript e imagens).
- No diretório raiz, o arquivo Program.cs é o ponto de entrada da aplicação, configurando serviços essenciais e o pipeline de middleware.

Configuração e Pipeline de Middleware

- O Program.cs usa o modelo de hospedagem minimalista para criar o builder da aplicação, registrar serviços MVC e construir o app.
- O pipeline de middleware é configurado em ordem: página de exceção para desenvolvimento, redirecionamento HTTPS, roteamento, autorização, serviço de arquivos estáticos e configuração das rotas MVC.

Componentes MVC e Injeção de Dependência

- Os controladores herdam da classe Controller, ganhando funcionalidades como renderização de views e binding de modelos.
- A injeção de dependência é exemplificada no construtor do controlador, que recebe um logger automaticamente fornecido pelo container DI.
- As views Razor combinam marcação HTML com código C#, usando arquivos como Index.cshtml para conteúdo específico e Layout.cshtml para estrutura comum.

Configuração e Execução da Aplicação

- O arquivo appsettings.json contém configurações da aplicação, como níveis de log e hosts permitidos.
- Ao executar a aplicação, o navegador exibe a página renderizada com o layout e conteúdo definidos, além de carregar os arquivos estáticos via middleware.
