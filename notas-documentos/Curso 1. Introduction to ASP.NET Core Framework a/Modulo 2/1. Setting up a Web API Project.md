Arquivos principais na configuração da API

- program.cs: ponto de entrada que configura serviços, middleware e o host para gerenciar o ciclo de vida da aplicação.
- startup.cs: gerencia a configuração do middleware, serviços, roteamento e o processamento das requisições.

**Controllers e endpoints da API**

- Controllers: classes que lidam com requisições HTTP e definem a lógica para responder a elas, funcionando como ponte entre as requisições e os dados ou ações.
- Endpoints: URLs específicas que permitem aos clientes interagir com a API, definidos por métodos dentro dos controladores.
![[Pasted image 20261002131249.png]]


**Roteamento e métodos HTTP**

- Roteamento: mapeia requisições HTTP para os métodos corretos nos controladores, podendo ser configurado por convenção ou por atributos para maior controle.
- **Configure routing -> Convention-based routing** 
	- Ex: `/api/products`
	- Custom attribute routing: `[HttpGet("products/{id}")]` ---> endpoint: `/api/products/{id}`
- Métodos HTTP: ações comuns usadas em APIs, como GET para obter dados, POST para criar, PUT para atualizar e DELETE para remover dados.
