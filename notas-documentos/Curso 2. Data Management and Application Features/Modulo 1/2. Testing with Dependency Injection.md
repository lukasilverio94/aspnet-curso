
### Unit Testing
A software testing method where individual units or components of a software are tested in isolation from the rest of the application

## Mocking
Creating simulated objects or services that replicate the behavior of real ones to isolate and test specific components
Easier to find and fix issues

## Steps to Conduct a Unit Test
1. Setup the test environment
2. Set up the mock
3. Write the unit test
4. Use a test runner

### Create Mock Services
1. Install the framework with a package manager
2. Configure the mock service
3. Simulate behavior of external service
4. Inject the mock service into the component
5. Run the component with the mock service


### Unit test
1. Define output conditions
2. Call the method in the component
3. Verify the component's output matches
