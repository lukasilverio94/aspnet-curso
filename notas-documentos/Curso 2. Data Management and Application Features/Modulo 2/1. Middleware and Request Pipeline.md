## Concept of Middleware

Middleware em ASP.NET Core: Gerenciando requisições HTTP de forma modular

Definição e papel do middleware

- Middleware é um software que atua como ponte entre front end e back end, facilitando comunicação e gerenciamento de dados.
- Em ASP.NET Core, middleware controla o processamento das requisições HTTP por meio de uma pipeline, onde cada componente executa uma tarefa específica.

Funcionamento da pipeline de middleware

- A pipeline é uma sequência de componentes que processam a requisição, como autenticação, logging e recuperação de dados.
- Cada middleware realiza sua função e passa a requisição para o próximo, garantindo um fluxo organizado e eficiente.

Componentes middleware embutidos em ASP.NET Core

- UseAuthentication verifica se o usuário está autenticado antes de permitir acesso a áreas protegidas.
- UseRouting direciona as requisições para o controlador e método corretos com base na URL, funcionando como um sistema de navegação.

Para configurar uma pipeline de middleware em um projeto ASP.NET Core, você deve seguir estes passos principais:

1. No arquivo **Startup.cs** (ou no Program.cs em versões mais recentes), localize o método **Configure**.
    
2. Dentro do método **Configure**, utilize os métodos de extensão para adicionar os componentes middleware na ordem desejada. Por exemplo:
```cs
public void Configure(IApplicationBuilder app, IWebHostEnvironment env)
{
    app.UseRouting(); // Define o roteamento das requisições

    app.UseAuthentication(); // Verifica autenticação do usuário

    app.UseAuthorization(); // Verifica autorização após autenticação

    app.UseEndpoints(endpoints =>
    {
        endpoints.MapControllers(); // Mapeia os controladores para as rotas
    });
}
```

## Middleware Pipeline
- O pipeline é composto por várias etapas (middlewares) que executam tarefas específicas, como registrar atividades, verificar autenticação e tratar erros.
- Cada middleware processa a requisição e a passa para o próximo até que uma resposta seja gerada e enviada ao usuário.

Fluxo de Requisições no Pipeline

- A requisição do usuário entra no pipeline e passa por middlewares como logging, autenticação e lógica da aplicação.
- A autenticação é crucial para proteger recursos, interrompendo o fluxo se o usuário não estiver autorizado.

Exemplo Prático com Groove Echo

- Ao acessar uma página de produtos, a requisição passa pelo registro de atividades, verificação de login, processamento dos dados do produto e, finalmente, a resposta é enviada ao navegador.
- A ordem dos middlewares é importante para garantir segurança e eficiência no processamento das requisições.
